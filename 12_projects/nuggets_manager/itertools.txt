••• Python - itertools -  product
Cartesian product of input iterables.  Equivalent to nested for-loops.

Example
--------
from itertools import product

a=[1,2]
b=[3,4]
p=product(a,b)
print(list(p))
>>>[(1, 3), (1, 4), (2, 3), (2, 4)]

p=product(a,b,repeat=2)
print(list(p))
>>>[(1, 3, 1, 3), (1, 3, 1, 4), (1, 3, 2, 3), (1, 3, 2, 4), (1, 4, 1, 3), (1, 4
, 1, 4), (1, 4, 2, 3), (1, 4, 2, 4), (2, 3, 1, 3), (2, 3, 1, 4), (2, 3, 2, 3
), (2, 3, 2, 4), (2, 4, 1, 3), (2, 4, 1, 4), (2, 4, 2, 3), (2, 4, 2, 4)]


••• Python - itertools -  count(start=0, step = 1)
The count iterator will return evenly spaced values starting with the number
you pass in as its start parameter. Count also accept a step parameter.

Example
--------
from itertools import count
for i in count(10):
    if i > 20:
        break
    else:
        print(i)

••• Python - itertools -  compress(data, selectors)
The compress itertool is useful for filtering the first iterable with the
second. This works by making the second iterable a list of Booleans (or ones and
zeroes which amounts to the same thing).

Example
--------
from itertools import compress
letters = "ABCDEFG"
bools = [True, False, True, True, False]
list(compress(letters, bools))

••• Python - itertools -  dropwhile(predicate, iterable)
Drops elements that doesn't meet the criteria and STOP without checking more
values.

••• Python - itertools -  groupby(iterable, key=None)
The groupby iterator will return consecutive keys and groups from your
iterable.

Example
-------
from itertools import groupby

zipcodes = [("sergio", 11100), ("dani", 11100), ("carlos", 28039),
            ("alicia", 28039), ("clara", 28040)]

sorted_zipcodes = (sorted(zipcodes))

for _, group in groupby(sorted_zipcodes, lambda name: name[0]):
    for name, zipcode in group:
        print(f"name:{name} zipcode:{zipcode}")

••• Python - itertools -  zip_longest(*iterables, fillvalue=None)

••• Python - itertools -  accumulate
Return series of accumulated sums (or other binary function results).

Example
--------
from itertools import accumulate
import operator
a = [1,2,3,4,5]
acc = accumulate(a)
print(list(acc))
>>>[1, 3, 6, 10, 15]

acc = accumulate(a, func=operator.mul)
print(list(acc))
>>>[1, 2, 6, 24, 120]
