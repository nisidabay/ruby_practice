# kittycmd - Kitty Config Generator

Generate Kitty terminal keyboard shortcuts from a YAML definition.

## Usage

```bash
kittycmd <command> [options]
```

### Commands

| Command | Description |
|---------|-------------|
| `generate` | Generate kitty.conf shortcuts |
| `dump` | Export current shortcuts to YAML/JSON |
| `validate` | Validate kitty.conf |
| `actions` | List available actions |
| `import` | Import from kitty.conf |
| `export` | Export to file |

### Options

| Option | Description |
|--------|-------------|
| `-c, --config FILE` | Config file path |
| `-o, --output DIR` | Output directory |
| `--dry-run` | Preview without changes |
| `-h, --help` | Show help |

## Input Format (YAML)

Create `shortcuts.yaml`:

```yaml
navigation:
  "ctrl+shift+up": previous_tab
  "ctrl+shift+down": next_tab
  "ctrl+shift+t": new_tab
  "ctrl+shift+w": close_tab
  "ctrl+tab": next_tab
  "ctrl+shift+tab": previous_tab

clipboard:
  "ctrl+shift+c": copy_to_clipboard
  "ctrl+shift+v": paste_from_clipboard
  "ctrl+shift+s": paste_selection

layout:
  "ctrl+shift+]": next_window
  "ctrl+shift+[": previous_window
  "ctrl+shift+enter": new_window
  "ctrl+shift+q": close_window

zoom:
  "ctrl+shift+equal": change_font_size all +2.0
  "ctrl+shift+minus": change_font_size all -2.0
  "ctrl+shift+backspace": change_font_size all 0

search:
  "ctrl+shift+f": launch --type=overlay search_regex
  "ctrl+shift+r": launch --type=overlay search_regex @selection
```

## Generate Config

```bash
# From YAML file
kittycmd generate shortcuts.yaml

# Output to file
kittycmd generate shortcuts.yaml > ~/.config/kitty/shortcuts.conf

# Preview without writing
kittycmd generate --dry-run shortcuts.yaml
```

## Output (kitty.conf)

```ini
# Generated by kittycmd
# 2026-04-12 10:30

# Navigation
map ctrl+shift+up previous_tab
map ctrl+shift+down next_tab
map ctrl+shift+t new_tab
map ctrl+shift+w close_tab
map ctrl+tab next_tab
map ctrl+shift+tab previous_tab

# Clipboard
map ctrl+shift+c copy_to_clipboard
map ctrl+shift+v paste_from_clipboard
map ctrl+shift+s paste_selection

# Layout
map ctrl+shift+] next_window
map ctrl+shift+[ previous_window
map ctrl+shift+enter new_window
map ctrl+shift+q close_window
```

## Dump Current Config

```bash
# Export current config to YAML
kittycmd dump > shortcuts.yaml

# Export to JSON
kittycmd dump json > shortcuts.json
```

## Validate Config

```bash
# Check for invalid actions
kittycmd validate ~/.config/kitty/kitty.conf
# ✗ Line 45: Unknown action: spwan "alacritty"
# ✗ Line 52: Unknown action: goto_tabl
# 2 errors, 0 warnings
```

## Available Actions

```bash
# List all actions
kittycmd actions

# Filter actions
kittycmd actions scroll
kittycmd actions tab
kittycmd actions copy
```

Common actions:
- `copy_to_clipboard`, `paste_from_clipboard`
- `new_tab`, `close_tab`, `next_tab`, `previous_tab`
- `new_window`, `close_window`
- `scroll_line_up`, `scroll_line_down`, `scroll_page_up`, `scroll_page_down`
- `change_font_size`
- `launch`, `kitten`

## Import from kitty.conf

```bash
# Create YAML from existing config
kittycmd import ~/.config/kitty/kitty.conf
```

## Integration with Kitty

### Append to Config

```bash
kittycmd generate shortcuts.yaml >> ~/.config/kitty/kitty.conf
```

### Separate File

```bash
kittycmd generate shortcuts.yaml > ~/.config/kitty/shortcuts.conf
```

Then in `kitty.conf`:

```ini
# Include shortcuts
include shortcuts.conf
```

## Category Organization

Organize shortcuts by category:

```yaml
# shortcuts.yaml
window:
  "ctrl+shift+enter": new_window
  "ctrl+shift+q": close_window

tab:
  "ctrl+shift+t": new_tab
  "ctrl+shift+w": close_tab

# Comments preserved in output
```

## Installation

```bash
cp kittycmd ~/.local/bin/
chmod +x ~/.local/bin/kittycmd
```

## Example Workflow

### Create Custom Layout

1. Create YAML:
```bash
vim shortcuts.yaml
```

2. Generate:
```bash
kittycmd generate shortcuts.yaml > ~/.config/kitty/shortcuts.conf
```

3. Test in Kitty:
```bash
kitty --config ~/.config/kitty/kitty.conf
```

4. Iterate and regenerate.

### Share Configurations

```bash
# Export for sharing
kittycmd dump yaml > my-kitty-shortcuts.yaml

# Import from friend
kittycmd generate friends-shortcuts.yaml > ~/.config/kitty/friend.conf
```

## Notes

- Unknown actions are commented with warning
- Categories become comment sections in output
- Key combinations validated against Kitty syntax
- Works with Kitty 0.20+
