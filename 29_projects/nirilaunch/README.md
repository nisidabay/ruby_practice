# nirilaunch - Niri Quick Launcher Generator

Generate app launchers and keybind configs for Niri (Wayland compositor).

## Usage

```bash
nirilaunch <command> [options]
```

### Commands

| Command | Description |
|---------|-------------|
| `scan` | Scan for .desktop files |
| `generate` | Generate launcher configs |
| `bind <app> <key>` | Generate single keybind |
| `toggle <app>` | Generate toggle script |
| `list` | List available apps |
| `search <query>` | Search apps |
| `export <format>` | Export to file |

### Options

| Option | Description |
|--------|-------------|
| `-o, --output FORMAT` | Output format: kdl, yaml, sh |
| `-l, --launcher NAME` | Launcher: fuzzel, rofi |
| `-h, --help` | Show help |

## Examples

### Scanning Apps

```bash
# Scan for all .desktop entries
nirilaunch scan
# Found 150 applications

# List available apps
nirilaunch list

# Search for specific app
nirilaunch search firefox
nirilaunch search terminal
```

### Generate Configs

```bash
# Generate KDL for niri config
nirilaunch generate > ~/.config/niri/launchers.kdl

# Generate YAML
nirilaunch generate --output yaml > launchers.yaml

# Generate shell script
nirilaunch generate --output sh > launchers.sh
```

### Single Keybind

```bash
# Generate bind for specific app
nirilaunch bind firefox "Mod+Shift+f"
# // Firefox
# binds {
#   Mod+Shift+f { spawn "firefox"; }
# }

# Generate bind with key suggestion
nirilaunch bind alacritty "Mod+Return"
```

### Toggle App

Generate script to launch/focus app:

```bash
nirilaunch toggle firefox
# spawn-or-focus "firefox"
```

## Output Formats

### KDL (Niri config)

```bash
nirilaunch generate --output kdl
```

```kdl
// Generated by nirilaunch
binds {
    Mod+Return { spawn "alacritty"; }
    Mod+e { spawn "thunar"; }
    Mod+f { spawn "firefox"; }
}
```

### YAML

```bash
nirilaunch generate --output yaml
```

```yaml
apps:
  - name: Firefox
    exec: firefox
    icon: firefox
    categories: [Web Browser, Network]
  - name: Alacritty
    exec: alacritty
    icon: terminal
    categories: [Terminal Emulator]
```

### Shell Script

```bash
nirilaunch generate --output sh
```

```bash
#!/bin/bash
# Generated by nirilaunch

# Super+Return: Alacritty
# Super+e: Thunar
# Super+f: Firefox

# Usage: source this file or add binds to your niri config
```

## Integration with Niri

### Add to Config

```bash
# Generate keybinds
nirilaunch generate >> ~/.config/niri/config.kdl

# Or include from separate file
nirilaunch generate > ~/.config/niri/launchers.kdl
```

Then in your main config:

```kdl
// ~/.config/niri/config.kdl
include "launchers.kdl"
```

### Custom Launchers

Create custom layout:

```bash
# Edit cached apps
$EDITOR ~/.config/nirilaunch/apps.cache
```

## Configuration

Cache stored in `~/.config/nirilaunch/apps.cache` (YAML format).

## Desktop Entry Parsing

Scans:
- `/usr/share/applications/`
- `/usr/local/share/applications/`
- `~/.local/share/applications/`

Parses:
- `Name=` - Application name
- `Exec=` - Command to run
- `Icon=` - Icon name
- `Categories=` - Categories
- `Comment=` - Description
- `Terminal=` - Run in terminal
- `NoDisplay=` - Skip hidden apps

## Installation

```bash
cp nirilaunch ~/.local/bin/
chmod +x ~/.local/bin/nirilaunch
```

## Example Workflow

### Setup Common Launchers

```bash
# Scan available apps
nirilaunch scan

# Generate binds for common apps
nirilaunch bind alacritty "Mod+Return" >> ~/.config/niri/config.kdl
nirilaunch bind firefox "Mod+f" >> ~/.config/niri/config.kdl
nirilaunch bind thunar "Mod+e" >> ~/.config/niri/config.kdl
nirilaunch bind code "Mod+c" >> ~/.config/niri/config.kdl
```

### Fuzzel/Rofi Integration

```bash
# Generate YAML for fuzzel
nirilaunch export yaml > ~/.config/fuzzel/apps.yaml

# Generate for rofi
nirilaunch export json > ~/.config/rofi/apps.json
```
