••• Sort - Sort a file in ascending order 
sort path/to/file

••• Sort - Sort a file in descending order  
sort --reverse path/to/file
sort -r path/to/file

••• Sort - Sort a file in case-insensitive way 
sort --ignore-case path/to/file
sort -f path/to/file

••• Sort - Sort a file using numeric rather than alphabetic order 
sort --numeric-sort path/to/file
sort -n path/to/file
sort -k number path/to/file

••• Sort - Sort `/etc/passwd` by the 3rd field, using "" as a field separator 
sort --field-separator= --key=3n /etc/passwd

••• Sort - Sort a file preserving only unique lines 
sort --unique path/to/file
sort -u path/to/file

••• Sort - Sort a file in place 
sort --output=path/to/file path/to/file

••• Sort - Sort numbers with exponents 
sort --general-numeric-sort path/to/file

••• Sort - Sort cluttered lines in a sorted file
sort -c path/to/file

••• Sort - Sort by months 
sort -M path/to_file

••• Sort - Sort a file using numeric key
sort -k number path/to/file

••• Sort - Sort by a tab delimiter
sort -t number path/to/file

••• Sort - Sort by key 3, tab as delimiter, numeric and reverse order
sort -k 3 -t -n -r path/to/file
