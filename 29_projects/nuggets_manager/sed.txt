••• Sed - inplace editing with backup••

••• Sed - inplace editing
sed -i 's/blue/green/' file1 file2

••• Sed - inplace editing with prefix backup name
sed -i'bkp.*' 's/blue/green/' file

••• Sed - place backups in different directory
sed -i'backups/*' 's/blue/green/' file

••• Sed - conditional execution. Only lines containing 2
sed '/2/ s/,/-/g' file

••• Sed - conditional execution. Lines not containing 2
sed '/2/! s/,/-/g' file

sed -n 's/1/one/gp' file
