••• Python - datetime - Get today date as string
The datetime.date.today() function creates a datetime object with the current 
date that can be reformatted using the strftime('%Y-%m-%d') method call to 
print out the current date in a specific format (year-month-day).

import datetime
today = datetime.date.today()
print(today.strftime("%d-%m-%Y"))
