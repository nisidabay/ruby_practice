••• C_language_tips: Pointer Cautions

An uninitialized pointer has some value; you just don’t know what it is. In many
cases, it is zero. If you use an uninitialized pointer in an assignment
statement, this is what happens:

*ptr = 12;

The value 12 is assigned to whatever address ptr points to. That address can be

full system crash.

••• C_language_tips: Caution with functions that manage pointers as data 

When you use gets() or any other function that stores data using a pointer, be
sure that the pointer points to allocated space. It’s easy to make a mistake
such as this: 
    char *ptr; 
    gets(ptr);
The pointer ptr has been declared but not initialized. It points somewhere, but

initialized to point somewhere, so it simply goes ahead and stores the entered
string at whatever address is contained in ptr. The string might overwrite

compilers won’t catch this type of mistake, so you, the programmer, must be
vigilant.

••• C_language_tips: Global Variables Scope

Declared outside of all blocks
Not stored on the stack
Scope is the remainder of the source file
If declared static, it prevents access from other source files

••• C_language_tips: Local Variables Scope

Declared at the beginning of a block
Stored on the stack
Scope is throughout the block
If declared static, the variable is not stored on the stack and keeps its value
for the entire duration of the program

••• C_language_tips: Formal Parameters Scope

Declared in the function header
Stored on the stack
Scope is throughout the function
Cannot be declared as static

••• C_language_tips: Range of integer types

Macros defined in <limits.h>

#include <limits.h>
#include <stdio.h>

int main() {
    printf("char: %d to %d\n", CHAR_MIN, CHAR_MAX);
    printf("short: %d to %d\n", SHRT_MIN, SHRT_MAX);
    printf("int: %d to %d\n", INT_MIN, INT_MAX);
    printf("long: %ld to %ld\n", LONG_MIN, LONG_MAX);
    return 0;
}
