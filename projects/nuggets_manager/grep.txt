••• grep -  Options:
    * -A Show number of lines after the match
    * -B Show number of lines before the match
    * -b Print the position of the match
    * -C Show number of lines around the match
    * -c Show the files and number of matches
    * --color Display matched patterns in colors
    * -e Use the following pattern; useful for multiple strings and special
    * -E Use regexp
    * -F Match exact word
    * -H Print filename
    * -h Suppress the Unix file name prefix on output
    * -i Case insensitive
    * -I Ignore binary files
    * -l Show what files contain the match
    * -L Show what files do not contain the match
    * -m Limit the printed lines of the match
    * -n Print line number
    * -P Perform a Perl compatible regexp
    * -o Print only the matched string in separate line
    * -q Quiet output
    * -r Recursive search in directories
    * -R Just like -r but follow all symlinks
    * -v Invert match. Lines that don't match
    * -w Match whole words
    * -x Match the expression in the whole line

••• Matching regular expression in files

Let us explain how you can use Regular Expressions in your egrep search:

| Repet operator | Use                                                                  |
| ---------------|-------------------------------------------------------------         |
| ?              | The preceding item before ? is optional and matched maximum one time |
| *              | The preceding item before * will be matched zero or more times       |
| +              | The preceding item before + will be matched one or more times        |
| {n}            | The preceding item is exactly matched n number of times.             |
| {n,}           | The preceding item is matched n or more times                        |
| {,m}           | The preceding item is matched maximum m times                        |
| {n,m}          | The preceding item is matched at least n but not more than m times   |
