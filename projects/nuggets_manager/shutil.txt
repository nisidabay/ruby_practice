••• Python shutil - Copy the file to a new location

••• Python shutil - Copy the file and preserve metadata
import shutil
shutil.copy2('test.txt', 'test_copy_with_metadata.txt')

••• Python shutil - Copy only the contents of the file
import shutil
shutil.copyfile('test.txt', 'test_copyfile.txt')

••• Python shutil - Move the file to a new directory
import shutil
shutil.move('test.txt', 'new_directory/test.txt')

••• Python shutil - Delete the directory and its contents
import shutil

••• Python shutil - Create a zip archive of a directory
import shutil
shutil.make_archive('directory_backup', 'zip', 'directory_to_backup')

••• Python shutil - Unpack a zip archive
import shutil

••• Python shutil - Get disk usage statistics for a given path
