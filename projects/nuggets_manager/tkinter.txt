••• Python - tkinter - Interactively change the behavior of a widget
import tkinter
from tkinter import ttk

class MyFrame(ttk.Frame):
    def __init__(self, master):
        super().__init__(master)
        self.style_database = ttk.Style(self)
        self.style_database.map("my_fancy.TButton",
                               background=[("pressed", "cyan"),
                                           ("active", "green"),
                                           ("focus", "blue")],
                               highlightcolor=[("hover", "yellow"),
                                               ("!hover", "red")],
                               relief=[("pressed", "groove"),
                                       ("!pressed", "ridge")])

        self.button1 = ttk.Button(self,
                                   text="Press to disable Button1",
                                   command=self.toggle_button,
                                   style="my_fancy.TButton")
        self.button1.grid(column=0, row=0)
        self.button_enabled = True

    def toggle_button(self):
        self.button_enabled = not self.button_enabled
        if self.button_enabled:
            self.button1.config(text="Press to disable Button1", state=tkinter.NORMAL)
        else:
            self.button1.config(text="Button 1 Disabled", state=tkinter.DISABLED)

root = tkinter.Tk()
frame = MyFrame(root)
frame.pack()
root.mainloop()

••• Python - tkinter - Center widgets with grid
The pack() geometry manager can be used to center widgets automatically by
using options like expand=True and fill=tk.BOTH. 

However, when using the grid() geometry manager, you need to manually configure
the rows and columns to ensure that widgets are centered. 

This is typically done using grid_rowconfigure and grid_columnconfigure to set
the weight of rows and columns, allowing them to expand and center the widgets
within the grid.

# Configure the grid to center the widgets
self.root.grid_rowconfigure(0, weight=1)
self.root.grid_columnconfigure(0, weight=1)

••• Python - tkinter - Pack and Grid
They use different logic to lay out widgets. For this reason they cannot be 
combined inside the same parent widget. Once one widget is inserted using pack
or grid, all other widgets must use the same geometry manager. You can however
pack widgets into one frame, grid widgets into another, then pack/grid both of
those Frame widgets into the same parent widget.
